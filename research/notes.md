# 强化学习教学内容核查

资料核查日期：2026-10-30。网页采用代表性节点，不能称为完整发展史或截至今日的全部成就。没有为凑“最新”加入无法稳妥界定的 2026 节点。

## 面向初学者的主线

强化学习研究智能体如何通过与环境交互，学习让长期累积奖励更大的决策策略。可以把花园送包裹任务设为有限、完全可观测、确定转移的网格世界。真实强化学习还包含连续状态、随机环境、不完全可观测等更复杂情形。

建议顺序：先亲自试走 → 给状态、动作、奖励命名 → 区分即时奖励与长期回报 → 用 Q 值表达动作的长期价值 → 演示一次 Q-learning 更新 → 看探索如何带来新经验 → 再连接深度强化学习、策略梯度、历史与现实限制。

案例的最重要教学边界：程序可以知道“撞墙怎么办、终点在哪”来实现环境，但智能体的 Q 表必须从交互经历更新，不能用预先写好的最短路径冒充学习。可在页面明确“环境规则已知给模拟器；学习器通过反馈更新 Q 表”。训练后最佳路径是当前学到的贪心策略，不是保证最优。

## 公式与符号审核

采用 Sutton / Barto 常见时间下标，全文统一：在时刻 t 看到状态 S_t，采取动作 A_t，然后收到奖励 R_{t+1}，来到 S_{t+1}。教学中可以用小写 s、a、r、s′ 表示一次观测样本，但要说明与大写随机变量的对应。

1. 策略：π(a|s) = P(A_t=a | S_t=s)。直觉是“处在这个位置，选择这个动作的概率”。确定性策略是概率集中在一个动作的特例；策略不是整条路线。
2. 回报：G_t = R_{t+1} + γR_{t+2} + γ²R_{t+3} + … = Σ_{k=0}^{T−t−1}γ^k R_{t+k+1}。第一项不打折。0 ≤ γ ≤ 1；持续任务常设 γ < 1，有限回合可以用 γ=1。折扣因子调节未来奖励权重，不是成功概率或学习速度。
3. 动作价值：q_π(s,a) = E_π[G_t | S_t=s, A_t=a]。Q(s,a) 是算法存储的估计，不是已知真实分数。q_π 跟随当前策略的期望，q_* 跟随最优后续策略；不要混用。
4. Bellman 最优性关系：q_*(s,a) = E[R_{t+1} + γ max_{a′} q_*(S_{t+1},a′) | S_t=s,A_t=a]。文字是“这一步奖励 + 下一状态最佳长期价值的折扣”。随机环境要有期望；确定案例里可把已观测转移写成单次更新目标，不能称为普遍精确等式。
5. Q-learning 样本更新：Q(s,a) ← Q(s,a) + α[r + γ max_{a′}Q(s′,a′) − Q(s,a)]。α 是学习率，γ 是折扣因子，r 是这一步新收到的奖励。中括号是 TD 误差，“新目标减旧估计”；学习率取一部分修正量。
6. 终止处理：真正到达终点或其他定义的终止状态后，目标为 r，不再加 γ max Q。若设置单回合步数上限，须区分训练中人为截断与任务本身终止；教学可直接把最大步数列为任务终止规则，以避免不清楚的截断语义。
7. 数值例子：旧 Q=2，α=0.5，r=−1，γ=0.9，下一位置最佳 Q=6。目标=−1+0.9×6=4.4；误差=4.4−2=2.4；新 Q=2+0.5×2.4=3.2。若这一步直接送达，奖励=10，则目标=10，新 Q=6；不能再给终点虚构未来价值。
8. ε-greedy：概率 ε 随机从所有可选动作中选一个，概率 1−ε 选当前 Q 值最高的动作。随机分支也可能选到贪心动作；“最优动作概率为 1−ε”一般不精确。四动作、唯一贪心动作时，其被选概率为 1−ε+ε/4。Q 值并列时随机打破平局。

## 教学常见误区

- 奖励是设计者定义的反馈，不天然等于真正想要的目标；送达奖励配合步数代价可表达更快送达，但不当设计可能鼓励钻空子。
- 负奖励也有学习价值，稀疏奖励则可能让探索困难。不要说每一步都必须有人给正确答案。
- 强化学习不等于“只有正向激励”；它通过数值反馈改进决策。
- 一条路线回报高，不意味着每个沿途动作即时奖励都高。延迟收益与信用分配是主线。
- 一次走到终点不等于学会；应比较固定策略的评估成功率/路径长度，或者观察多回合趋势。
- 训练回报可能上下波动，尤其含探索；不要绘制必然单调上升的假学习曲线。图必须显示真实模拟结果，并注明训练数据与窗口均值。
- 若地图、奖励或 γ 改变，当前 Q 表需要重学或明确保留会造成旧经验偏差；默认重置最清楚。α 与 ε 改变可以继续训练。
- Q-learning 只是一个入口，不代表所有 RL 都建 Q 表。大状态空间常用神经网络；策略梯度直接优化策略，actor–critic 结合策略与价值。
- 简单案例是算法教学，不模拟机器人真实视觉、物理、硬件或安全约束。现实应用还需处理样本效率、分布变化、稳定性和奖励设计。

## 历史年份核查重点

- 1957 指 Bellman 著作出版，动态规划研究更早，心理学试错与最优控制也是 RL 的历史根源。
- Q-learning：1989 提出，1992 详细收敛证明，两个时间点都应保留。
- TD-Gammon：1992 的原论文报告中级/近专家水平；不能把 1993/1995 更强版本的评价直接写为“1992 夺得世界冠军”。
- DQN：2013 预印本 7 款游戏、3 款超过对比人类；2015 Nature 49 款，游戏分别训练。官方 2016 回顾页提 50 款，网页此处按 2015 原论文的 49 款。
- AlphaGo：2015 年战胜樊麾；2016 年 3 月 4:1 战胜李世石。2016 年 Nature 论文的首个职业胜局与李世石赛事不是同一个事件。
- AlphaZero：2017 年 12 月预印本、2018 年 Science 正式论文。AlphaGo Zero 的 2017 年 10 月论文是另一个系统，勿混淆。
- 2019 OpenAI Five 2:0 战胜 OG 是特定比赛设置；AlphaStar 宗师等级也对应评测版本与条件。
- 2022 InstructGPT 是 RLHF 的代表应用，不是 RLHF 的诞生年。
- 2025 DeepSeek-R1 的预印本与后来的 Nature 论文均可引用。R1-Zero 从预训练基础模型开始，未以监督微调作前置步骤；完整 R1 使用冷启动与多阶段流程。

学习路径可以表述为：有限 MDP 与回报 → 动态规划与 Monte Carlo → TD/SARSA/Q-learning → 函数近似与 DQN → 策略梯度 / actor–critic / PPO → 选择模型学习、离线 RL、多智能体或语言模型 RL 等分支。这是教学路线，不是严格的历史先后顺序。
